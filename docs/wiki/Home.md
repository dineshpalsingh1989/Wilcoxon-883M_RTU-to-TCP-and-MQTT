# Wilcoxon gateway installation wiki

This guide covers installation and registration for the 883M gateway on Adafruit Feather ESP32-S3, Cytron Maker ESP32 and Cytron IRIV IO Controller. It also explains the optional Wilcoxon PCC420V 4–20 mA input on the IRIV.

- [Installer and preflight](Installer-and-Preflight.md): supported boards, checks, and installation flow
- [Gateway identity and private registry](Gateway-Identity-and-Private-Registry.md): serial numbers, MAC addresses, and records
- [IRIV I/O and wiring](IRIV-IO-and-Wiring.md): analog inputs, digital I/O, and safe wiring references
- [Validation plan](Validation-Plan.md): automated evidence and remaining bench checks
- [Project plan](Project-Plan.md): tasks and completion criteria

Start with the [web installer](https://dineshpalsingh1989.github.io/Wilcoxon-883M_RTU-to-TCP-and-MQTT/). The [firmware repository](https://github.com/dineshpalsingh1989/Wilcoxon-883M_RTU-to-TCP-and-MQTT) contains the source and detailed setup documents.

This wiki contains no customer names, device MAC addresses, sensor serials, or installation keys. Installation records belong in the [private registry repository](https://github.com/dineshpalsingh1989/wilcoxon-install-records/issues).
