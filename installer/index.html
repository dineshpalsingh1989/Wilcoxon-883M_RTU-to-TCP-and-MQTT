2. Choose your board

ESP32 boards

The installer reads the chip on the connected board and installs the matching build automatically.

  • Adafruit Feather ESP32-S3 (ESP32-S3 chip)
  • Cytron Maker ESP32 (original ESP32 chip, ESP32-WROOM-32E). Status is shown on the onboard GPIO2 LED, the buzzer is GPIO26 and the user button is GPIO4.

Other boards are not tested. An ESP32-S3 board with at least 4 MB flash receives the Feather build and may work; another original-ESP32 board receives the Maker ESP32 build, which needs 8 MB flash. ESP32-S2, C3 and C6 boards are not supported; the installer will say so.

1. Before you start

  1. Use Chrome or Edge on a computer (Windows, macOS, Linux or ChromeOS). Phones and Firefox/Safari cannot flash over USB.
  2. Connect the board to the computer with a USB-C data cable. Charge-only cables will not show a port.
  3. Cytron Maker ESP32 on Windows or macOS: if no port appears, install the WCH USB-serial driver (CH9102/CH343) for the board's USB chip, then reconnect.

2. Install

Loading available versions…

Board not listed in the port window? Put it into download mode: hold BOOT, tap RESET (labelled EN on the Maker ESP32), release BOOT, then click Install again. After installing, press RESET/EN once to start the new firmware.

3. First-time setup

  1. On your phone or laptop, join the Wi-Fi network ILA_Sensor_AP (password 12345678).
  2. Open http://192.168.4.1.
  3. Go to Settings > Wi-Fi, save your network, then open the gateway at its new local IP address.
  4. Wire the RS485 module and sensor as shown in the wiring guide.

Already installed? Later updates can be done from the gateway itself under Settings > GitHub Firmware Updates, which keeps your settings.

Trouble installing?

Trying again is always safe: the board's built-in loader cannot be erased.

  • No port appears: use a USB-C data cable and another USB socket (no hub), then hold BOOT, tap RESET, release BOOT.
  • "Failed to connect" or timeout: close the Arduino IDE, PlatformIO or any serial monitor using the port, then use BOOT + RESET.
  • Stops halfway: change the cable and install again.
  • Finished but nothing happens: press RESET. Still no ILA_Sensor_AP? Install again with Erase device ticked.
  • "This device is not supported": the board's chip is not one of the supported boards above, or the release predates support for it. For an IRIV IO Controller, choose IRIV IO Controller at the top instead.

Other ways: download factory-adafruit_feather_esp32s3.bin (Feather) or factory-cytron_maker_esp32.bin (Maker ESP32) from the releases page and write it at address 0x0 with Espressif's browser flasher, esptool or Espressif's Flash Download Tool. This clears saved settings. Step-by-step instructions: installation guide.

Choosing Erase device during install clears saved Wi-Fi, MQTT and alarm settings. Leave it unticked to keep them.

IRIV IO Controller

The Cytron IRIV IO Controller uses a Raspberry Pi RP2350A chip, isolated RS485 and wired Ethernet. Its bootloader shows up on your computer as a USB drive, so you install by copying one file. This works in any browser on any computer.

1. Download

Loading available versions…

2. Install

  1. Connect the IRIV's USB-C (PROG) port to the computer with a data cable.
  2. With a paperclip, hold the BOOT pinhole button, press and release RESET, then release BOOT.
  3. A drive named RP2350 appears. Copy the downloaded .uf2 file onto it.
  4. The drive disappears and the IRIV restarts with the gateway firmware.

3. First-time setup

  1. Plug the IRIV's Ethernet port into your network and power it (10–30 V DC, or USB-C).
  2. Open http://ila-gateway-883m.local, or the address your router lists for ila-gateway-883m.
  3. No DHCP server, or a laptop plugged in directly? After 10 seconds without DHCP the gateway uses 192.168.4.1. Set your laptop to 192.168.4.2, mask 255.255.255.0, and open http://192.168.4.1. Holding the USER button for 5 seconds also switches to this address.
  4. Wire the sensor's RS485 A, B and ground to the IRIV's RS485 A, B, G terminals, as in the wiring guide. Turn on the RS485 termination switch underneath if the IRIV is at the end of the bus.

MQTT: the IRIV IO Controller supports plain MQTT on port 1883 only. MQTT over TLS (port 8883) is not supported, so cloud brokers that require TLS need an ESP32 board.

Updates: upload the new firmware-cytron_iriv_io_controller.bin under Settings > Device Diagnostics > Firmware Update, or copy the new .uf2 as above. Both keep your settings. One-click updates from GitHub are not available on this board yet.

MQTT waveforms: from v4.13.0, each waveform and each spectrum is sent as one complete MQTT message (up to about 110 KB), so your back end no longer joins pieces. Make sure your broker accepts messages of that size. How the messages look

MQTT topics: v4.13.0 also lets you choose your own topics. In Settings > MQTT, set Topics to Custom to send metrics, waveforms, spectra and health status to topics you pick, and to set the command topic your system uses to control the gateway. Default keeps today's topics. How topics and commands work
